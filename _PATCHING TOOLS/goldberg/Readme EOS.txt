Goldberg Epic Online Services (EOS) emulator.

To use just replace the EOSSDK-Win32-Shipping.dll or EOSSDK-Win64-Shipping.dll of the game with mine.

Default save location: C:\Users\<Your windows user name>\AppData\Roaming\Goldberg EOS Emu Saves\

In the settings folder in that save location you will find (if you have used the emulator at least once):
account_name.txt (Edit this file to change your name)


Note that the epic games launcher launches games with these command line parameters so your game might need to be launched with a combination of these to work correctly:

-AUTH_LOGIN=unused -AUTH_PASSWORD=901dbe79901dbe79901dbe79901dbe79 -AUTH_TYPE=exchangecode -epicapp=app_name -epicenv=Prod -EpicPortal  -epicusername="Goldberg" -epicuserid=aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa -epiclocale=en-US
