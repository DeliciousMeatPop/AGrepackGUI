DiskSpan_GUI 2.0.0.0 (x64) [2021.06.30]
- Changed CLS-DiskSpan.dll to a new modified version.
  >> To install from conversions that are on HDD in consecutively renamed folder the next part is obtained automatically. 
  >> Now DiskSpan_GUI supports other file extension formats like ".bin" or any other but needs a value of 1/#1 or #a/#A to increment the slices.
  >> But for that it is necessary to have a number "1" in the filename that will be incremented at each slice of the splited file.
  >> It also supports alphabetically incrementing using "#a" or "#1" in the data file name to force increment this value.
  >> To use the "#" character and not increment the number "1"/"a" after "#" then double character "##" so that it is incremented leftmost.
  >> Example: "Data#1.pc1" create slices "Data1.pc1", "Data2.pc1", "Data3.pc1", etc.
  >> Example: "Data#A.001" create slices "DataA.001", "DataB.001", "DataC.001", etc.
  >> Example: "Data1.bin" create slices "Data1.bin", "Data2.bin", "Data3.bin", etc.  
  >> Example: "Data1-001.bin" create slices "Data1-001.bin", "Data1-002.bin", "Data1-003.bin", etc. 
  >> Example: "Data#1-##1.bin" create slices "Data1-#1.bin", "Data2-#1.bin", "Data3-#1.bin", etc.
