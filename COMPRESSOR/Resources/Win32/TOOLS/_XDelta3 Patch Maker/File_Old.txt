DiskSpan_GUI 1.0.0.3 [2021.03.08]
- Fixed DropDown on elevated systems.
- Fixed the "Next" button that was enabled when the last tab was active after searching for a directory or method in config mode. 
- Fixed the MergeRecordsButton so that it is disabled when merging "Records.ini" to DLL or extracting "Records.ini" from DLL. 
- Added build check hash to check if the executable is compatible with "DS_Methods.ini" in the "Resources" folder when replacing only DiskSpan_GUI.exe. 
- Fixed the OodleRec8 method so that the "oo2core_8_win64.dll" library is renamed to "oo2core_8_win64.dll" automatically.
  >> The OodleRec executables do not support the name "oo2core_8_win64.dll"(8) so the need to automatically rename it to "oo2core_7_win64.dll" inside "Setup.dll". 
- Added support for others OodleRec methods: "oo2reck3", "oo2recm3" and "oo2recs3".
  >> The OodleRec executables do not support the name "oo2core_3_win64.dll"(3) so the need to automatically rename it to "oo2core_4_win64.dll" inside "Setup.dll". 
- Added new "xtool_kraken3" method support with XTool 2020.
  >> With XTool 2020 the library "oo2core_3_win64.dll" is included inside "Setup.dll" with its original name. 
- Added new XTool 2020 "Bethesda" plugin (R1) currently only supporting the game "The Elder Scrolls V: Skyrim" using "xtool_skyrim" method.
